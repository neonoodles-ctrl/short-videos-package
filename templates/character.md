# Character name

## Reference image

One clear, full-body picture of the character on a plain background, made with
workflows/local/still-klein9b.api.json (or the fal version) and approved by a person.
Every still of this character uses it as the REFERENCE image. If the reference shows a
room or a landscape, close-ups will copy that background; use a plain background.

## Things you can count

A still that breaks one of these is rejected, not retried with the same prompt.

- Body: species or type, size compared with the others, colours
- Head: ears (how many, shape), eyes, nose, mouth (teeth or no teeth)
- Hands: how many fingers and thumbs on each hand
- Clothes: each garment once, with its colour
- Props the character always carries

## One sentence for every prompt

Write the description you paste into every still prompt, word for word, so the character
looks the same in every shot. Example: "the purple felt bulldog from image 1, in her green
kimono with a mustard sash and a navy jacket, closed mouth with no teeth".

## Never

Things that must not appear on this character (extra limbs, teeth, a second tail, ...).
